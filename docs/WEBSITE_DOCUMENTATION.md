# وثيقة تصميم وتوثيق موقع صفحة الهبوط لنسخة Hudgram

تهدف هذه الوثيقة إلى تقديم توثيق شامل لفكرة وهيكل ومميزات موقع صفحة الهبوط الخاص بتطبيق **Hudgram**. يمثل هذا الموقع الواجهة التعريفية والتفاعلية الرسمية للنسخة، وسيتم تصميمه بأعلى المعايير البصرية الحديثة لضمان تجربة مستخدم مبهرة.

---

## 1. المتطلبات والخصائص الأساسية للموقع

### أ. دعم اللغتين (عربي/إنجليزي) والاتجاهات (RTL/LTR)
- **اللغة العربية (RTL):** يتم تطبيق اتجاه النصوص من اليمين إلى اليسار (`direction: rtl`)، مع استخدام خطوط متناسقة وعريضة (مثل خط **Cairo** من Google Fonts).
- **اللغة الإنجليزية (LTR):** يتم تطبيق اتجاه النصوص من اليسار إلى اليمين (`direction: ltr`)، مع استخدام خطوط تقنية رشيقة وعصرية (مثل خط **Outfit** أو **Inter**).
- **التبديل الديناميكي:** زر في أعلى الصفحة (الهيدر) يتيح التبديل الفوري للغة بدون إعادة تحميل الصفحة، من خلال تعديل خاصية `lang` و `dir` في وسم `<html>` واستخدام ملف ترجمة جافا سكريبت مدمج.

### ب. دعم الوضع الليلي والنهاري (Dark/Light Modes)
- **الوضع الليلي (الافتراضي):** يعتمد على درجات داكنة مريحة للعين من اللون الأزرق الليلي والأرجواني المتوهج مع عناصر زجاجية (Glassmorphism).
- **الوضع النهاري:** يعتمد على درجات فاتحة وناصعة متناسقة مع هوية تليجرام البيضاء والزرقاء الكلاسيكية.
- **آلية العمل:** يتم استخدام متغيرات CSS (CSS Variables) للتحكم بالألوان، ويقوم كود الجافا سكريبت بحفظ خيار المستخدم في المتصفح (`localStorage`) لجلب السمة المفضلة تلقائياً في الزيارات القادمة.

### ج. التقنيات والتوافقية (Responsive Design)
- **لغات البرمجة:** يتم برمجة الموقع بالكامل باستخدام اللغات القياسية: **HTML5** للبنية، **CSS3** للتصميم والحركات، و **Vanilla JavaScript** للتفاعلات والمحاكيات.
- **التوافق التام:** تصميم مرن وسريع الاستجابة (Responsive Layout) يتكيف بسلاسة مع كافة أحجام الشاشات:
  - الهواتف الذكية (شاشات صغيرة ورأسية).
  - الأجهزة اللوحية (التابلت).
  - أجهزة سطح المكتب والشاشات الكبيرة والمحمولة.
- **بدون أطر عمل ثقيلة:** الحفاظ على سرعة تحميل فائقة وتوافق تام مع محركات البحث (SEO).

## 2. هيكل مجلدات وملفات المشروع

سيتم تنظيم ملفات الموقع بشكل مرتب داخل مجلد رئيسي باسم `landing-page` في المشروع كالتالي:

```
landing-page/
├── index.html              # الصفحة الرئيسية للموقع (تضم كافة الأقسام الرئيسية)
├── privacy-policy.html     # صفحة سياسة الخصوصية المستقلة
├── style.css               # ملف التنسيقات والوضع الليلي والنهاري والتجاوبية
├── app.js                  # ملف التفاعلات البرمجية، محاكيات الميزات، وتغيير اللغات
└── assets/                 # مجلد الموارد الرئيسي
    ├── icons/              # الأيقونات والشعارات الرسومية (بصيغة SVG أو PNG)
    └── images/             # لقطات شاشات التطبيق، صور الهواتف الذكية، والخلفيات المتدرجة
```

## 3. الأقسام التفصيلية لصفحة الهبوط

### القسم الأول: الشاشة الرئيسية (Hero Section)
- **الوصف:** أول واجهة بصرية تعرض للمستخدم فور فتح الموقع وتعمل على لفت انتباهه بجماليتها.
- **المكونات:**
  - شريط التنقل العلوي (Navbar): يحتوي على شعار Hudgram، روابط التنقل السريع بين الأقسام، زر تبديل اللغة، وزر التبديل بين الوضعين المظلم والمضيء.
  - العنوان الرئيسي والتسويقي: عنوان جذاب يوضح تفوق نسخة Hudgram وقوتها كبديل متطور لتليجرام.
  - أزرار التحميل السريعة: أزرار واضحة ذات تأثيرات حركية للتحميل المباشر.
  - مجسم هاتف ثلاثي الأبعاد (3D CSS Phone Mockup): محاكاة بصري لعلبة هاتف ذكي تعرض لقطات واجهة التطبيق بشكل تفاعلي وجميل يتحرك مع حركة الفأرة.

### القسم الثاني: حول Hudgram وفكرته (About Hudgram)
- **الوصف:** قسم تعريفي يسرد رؤية النسخة ولماذا تم تطويرها.
- **المكونات:**
  - نص يوضح أن Hudgram هي نسخة مبنية على كود تليجرام الرسمي ومخصصة لتقديم تجربة تواصل متطورة خالية من القيود.
  - إبراز المبادئ الأساسية: السرعة، الخصوصية الفائقة، التنظيم والإنتاجية، وتخصيص الواجهة بالكامل.

### القسم الثالث: شبكة ومحاكي المميزات (Features Grid & Simulator)
- **الوصف:** استعراض الميزات العشر الرئيسية بشكل مرتب وبطاقات زجاجية.
- **المكونات تفاعلياً:**
  - بطاقات ميزات زجاجية (Glassmorphic Cards) مع تأثيرات حركية عند تمرير الفأرة (Hover).
  - **مختبر المحاكاة التفاعلي (Playground):** شاشات تفاعلية يمكن للمستخدم النقر عليها لتجربة الميزة مباشرة:
    - *محاكي الرد التلقائي*: كتابة كلمة (مثل: سلام) لرؤية رد فوري محاكى في صندوق محادثة وهمي.
    - *مترجم النصوص*: كتابة جملة وترجمتها وتنسيقها بشكل ثنائي مدمج.

### القسم الرابع: معرض لقطات شاشة التطبيق التفاعلي (Interactive App Screenshots Gallery)
- **الوصف:** معرض عرض مذهل يعرض من **4 إلى 9 لقطات شاشة (Screenshots)** حقيقية وجذابة للتطبيق، بحيث تمثل كل لقطة شاشة واجهة لميزة رئيسية بداخل Hudgram (مثل: شاشة الرد التلقائي، شاشة الجدولة، شاشة التحديثات، إلخ).
- **التصميم البصري التفاعلي:**
  - يتم تضمين الصور داخل مجسم هاتف ذكي أنيق (Smartphone Frame mockup) في وسط المعرض.
  - توفير أزرار تحكم جانبية (السهم الأيمن والأيسر) وأزرار نقطية سفلية (Pagination Dots) للتنقل التلقائي واليدوي بين لقطات الشاشة الـ 9.
  - بجانب مجسم الهاتف، يتم عرض عنوان الميزة الحالية المعروضة ووصف مختصر لها يتغير ديناميكياً مع تغير لقطة الشاشة النشطة، مما يسمح للمستخدم بفهم كل ميزة بصرياً وقرائياً بشكل فخم وسلس.

### القسم الخامس: سجل التغييرات والإصدارات (Changelog)
- **الوصف:** جدول زمني (Timeline) يوثق التحديثات والتطورات التي تطرأ على التطبيق في كل إصدار جديد باللغتين العربية والإنجليزية.
- **مفاتيح شارات التغيير (Badge System):**
  يتم تمييز كل سطر تغيير بشارة ملونة لتوضيح نوع التغيير للمستخدم:
  1. 🟢 **[إضافة / Add]** (اللون الأخضر): عند إضافة ميزة جديدة كلياً في هذا الإصدار.
  2. 🔵 **[تحسين / Improve]** (اللون الأزرق): لتحسين وتطوير ميزة أو قائمة موجودة مسبقاً.
  3. 🟠 **[إصلاح / Fix]** (اللون البرتقالي): لإصلاح مشكلة أو عطل برمجي تم الإبلاغ عنه.
  4. 🟣 **[تعديل / Update]** (اللون الأرجواني): لتعديل تصرف ميزة أو تغيير خيار واجهة.
  5. 🔴 **[حذف / Remove]** (اللون الأحمر): عند إزالة ميزة أو خيار غير مرغوب فيه.
  6. ⚪ **[تجريبي / Beta]** (اللون الرمادي): للميزات التجريبية المضافة للاختبار تحت التطوير.
- **تفاصيل السجل:** يظهر أمام كل شارة عنوان التغيير وسطر تفصيلي يشرح ماذا تم تعديله بالضبط.

### القسم السادس: بوابة التنزيل والتثبيت (Download & Install Portal)
- **الوصف:** قسم موحد يحتوي على كافة خيارات تحميل وتثبيت التطبيق بأمان.
- **مصادر التحميل الأربعة المعتمدة:**
  1. **ملف APK المباشر:** رابط لتحميل النسخة وتثبيتها يدوياً بأسرع وسيلة.
  2. **متجر Google Play:** لضمان تثبيت آمن وتحديثات تلقائية (عند التوفر).
  3. **مستودع GitHub Releases:** للوصول للتعليمات البرمجية والتحميل من المصدر المفتوح مباشرة.
  4. **قناة Telegram الرسمية:** لتحميل الملف المباشر للمشتركين بداخل القناة الرسمية للنسخة (`@hudgramchannel`).

### القسم السابع: الإبلاغ وتقديم الملاحظات (Feedback & Contact Form)
- **الوصف:** نموذج إرسال تفاعلي يتيح للمستخدمين مراسلة المطورين وإرسال ملاحظاتهم أو الإبلاغ عن أخطاء.
- **المكونات:**
  - حقول إدخال أنيقة: الاسم، البريد الإلكتروني، نوع الرسالة (اقتراح، إبلاغ عن مشكلة، شكر)، ونص الرسالة.
  - إرسال عبر البريد الإلكتروني: ربط الفورم بريدياً أو محاكاته تفاعلياً لإظهار إشعار إرسال مبهج (Toast Notification).

### القسم الثامن: سياسة الخصوصية (Privacy Policy)
- **الوصف:** صفحة مستقلة تماماً باسم `privacy-policy.html` تحافظ على نفس الأسلوب الجمالي للموقع الرئيسي.
- **المحتوى:**
  - توضيح أمان بيانات المستخدم وأن Hudgram لا يخزن أي بيانات شخصية أو محادثات على خوادم خارجية بل تعتمد على خوادم تليجرام الآمنة مباشرة.
  - تفصيل الصلاحيات المطلوبة مثل الوصول للكاميرا والمايكروفون والذاكرة وأسبابها لتثقيف المستخدمين وضمان شفافية التطبيق.

## 4. استراتيجية جماليات التصميم وتجربة المستخدم (Aesthetics & UX)

- **المؤثرات البصرية:**
  - تأثير زجاجي (Backdrop filter blur) يعطي شعوراً بالفخامة والشفافية.
  - تدرجات لونية متحركة في الخلفية لمحاكاة طيف الألوان المريح.
  - استخدام أيقونات مخصصة SVG عالية الجودة لتجنب تشوه الصور في الشاشات الكبيرة.
- **سهولة التصفح:**
  - شريط علوي يثبت عند التمرير (Sticky Navigation) لسهولة التنقل.
  - زر العودة للأعلى (Back to Top) يظهر ديناميكياً عند النزول لأسفل الصفحة.
  - انتقالات سلسة (Smooth scrolling) بين الأقسام.
